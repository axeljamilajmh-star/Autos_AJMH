# Autos_AJMH

**Alumno:** Axel Jamil Molina Huete

**Propósito:** Diseño y modelado de la base de datos para el dominio "Autos". 
Contiene: modelo ER (ER-Studio), scripts para SQL Server (creación de BD y tablas), y consultas de ejemplo.

## Estructura del repositorio
- ER-Diseño/ : modelo fuente (ER-Studio) y exportación gráfica (.png/.pdf)
- script/ : scripts SQL para crear la base de datos, tablas, inserts y consultas

## Cómo ejecutar
1. Abrir SQL Server Management Studio y ejecutar `script/00_create_database.sql`
2. Ejecutar `01_create_tables.sql` y luego `02_inserts.sql`
3. Ejecutar `03_consultas.sql` para ver consultas ejemplo
